ONE App

One platform for every department, layered on the company's ERP. One login, one codebase, two legal entities. Click any box for module-level detail.

The ERP contract. The ERP database is strictly read-only — SELECT with NOLOCK, never a write. Everything the organisation authors itself lives in a writable companion database, with an audit stamp on every row.

The human's whole job, by role

What this is

  • A read-mostly business platform over a NAV-style ERP, with a writable companion database for everything the organisation authors itself.
  • Six live departments share one login, one role model, one company switcher and one set of rails.
  • Field staff run it inside a thin Android shell that loads the live site, so UI changes ship without an APK rebuild.
